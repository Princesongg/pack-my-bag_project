# 대만 공식 기후 데이터 및 MY BAG 연동

확인일: 2026-10-25. 현재 지원하는 대만 도시 **타이베이·가오슝 전체**를 구현했다. 도시 목록 추가·삭제는 없다.

## 출처·기준·검증

대만 중앙기상서(CWA)의 [기후 월평년값](https://www.cwa.gov.tw/V8/C/C/Statistics/monthlymean.html) 공개 HTML 표를 사용했다. 모든 채택 항목의 두 도시 행에 **1991~2020**이 명시되어 있다. 계정·결제·키가 필요 없는 공개 파일만 개발 중 다운로드했으며 앱은 정적 데이터를 사용한다.

- 타이베이: 臺北 / Taipei, **466920**. CWA [관측소 이력](https://climate.cwa.gov.tw/data/pdf_1.pdf)과 [통계 산출 설명](https://climate.cwa.gov.tw/data/pdf_2.pdf)에는 1992.02–1997.08의 **466921** 연결이 기록되어 있다. CWA가 게시한 도시별 평년값을 그대로 사용하며 관측소별 원자료를 자체 연결하거나 균질성 보정하지 않았다.
- 가오슝: 高雄 / Kaohsiung, **구 관측소 467440**. 월평년값 페이지가 구 관측소 기준을 명시한다. [TCCIP 관측자료 안내](https://tccip.ncdr.nat.gov.tw/ds_01.aspx)는 2022-01-24 관측소 이전을 안내한다. 이후 신 관측소 **467441** 값을 이 평년값과 혼합하지 않는다.
- 평균기온: `Taiwan_tx.html`의 공식 제공값을 직접 사용. 최고·최저의 산술평균으로 대체하지 않는다.
- 평균 일최고·일최저: `Taiwan_meantxmax.html`, `Taiwan_meantxmin.html`. CWA 산출 설명은 월평균 최고·최저와 **절대 최고·최저 극값**을 별도 분류한다. 원본 월평년값 표의 평균 항목만 채택했다.
- 강수량: `Taiwan_precp.html`의 월누적 강수량 평균. 중위수 표를 사용하지 않는다.
- 상대습도: `Taiwan_rh.html`, 단위 %. 강수일수: `Taiwan_precpday.html`, **일강수량 ≥0.1mm**인 날의 월평균 일수. 실제 여행일의 강수 확률이 아니다.

원본 HTML·통계 설명 PDF·관측소 이력 PDF와 SHA-256은 `src/service/data/raw/tw/`에 보관한다. 원본 행·12개월 셀·통계기간을 검사하는 오프라인 생성 스크립트는 비수치·결측·중복 행·예상 밖 기간을 거부한다. 기존 국가 자료를 대체하지 않는다.

## 공통 경로 연결

`getClimateMonth` → 공통 정적 관측소 평년값 어댑터 → 기존 `getTripClimate` → 공통 TripBrief / WeatherGuide / getClothingPreview / getDefaultBagItems 경로를 사용한다. 국가별 카드·추천·체크리스트 로직은 복제하지 않았다.

수치는 기존 PC 34px / 모바일 30px를 유지한다. 상세 팝업에는 평균·평균 최고·평균 최저·강수량·습도·강수일수·관측소·기준기간·출처·추천 이유가 나온다. 두 달 이상 여행은 기존 월 전환을 사용한다. TWD 통화, 현지 시각 및 시차, 시차 팝업 제거 상태는 유지했다.

추천은 기존 서비스 규칙을 사용한다. 타이베이 1월은 얇은 긴팔·얇은 외투, 7월은 반팔·우산 및 우비, 가오슝 1월은 얇은 긴팔·가디건이 후보가 된다. 편한 운동화는 관광·야외활동 목적 조건에 따른다. 출장 셔츠 등 목적 필터도 유지한다. 습도와 높은 기온이 함께 해당하면 통풍·건조가 쉬운 옷감 검토 문구를 추가한다. 공식 기관의 복장 권고로 표시하지 않으며 같은 물품 ID로 체크리스트에 중복 없이 연결한다.

## 실제 화면 검증

Chrome CDP로 실제 **국가 선택 → 도시 선택 → 날짜·목적·수하물 입력 → MAKE MY BAG 제출 → 카드 → 상세 모달 → 체크리스트**를 실행했다. 저장된 여행 데이터를 주입해 생성 흐름을 생략하지 않았다. 테스트 날짜는 미래의 2099년(연말은 2100년 1월까지)으로 두어 실제 예보와 무관한 월평년값 동작을 검증했다.

- PC **1440×1000**, 모바일 **390×1000**, 각각 7개 시나리오 = **14개 흐름 통과**.
- 타이베이 1월 16.4°C / 7월 29.9°C / 11월 21.9°C.
- 가오슝 1월 19.7°C / 7월 29.4°C. 도시 고유 값과 추천 후보 확인.
- 타이베이 12월 18.2°C → 다음 해 1월 16.4°C 월 탭 전환 확인.
- 일본 오사카 11월 **14.2°C** 유지.
- 요약 카드·모달 수치 일치, 평균 최고·최저 표시, 출처·기간·안내문, 추천 ID와 체크리스트 대응 확인.
- PC 세 카드 높이 일치(약 211.55px), 모바일 기존 세로 배치 유지. 전체 페이지·모달 가로 넘침 없음. 기온 수치 34px / 30px 확인.
- 타이베이 11월 체크 상태가 새로고침 후 복원됨. TWD 표시와 현지 시각을 화면에서 확인.
- 브라우저 예외 0건. 검증 중 외부 요청 **0건**. 실시간 날씨·과금 API·신규 키·서버/DB 인프라 추가 없음.
- 전체 단위·데이터 테스트 **60개 통과**. TypeScript 및 Vite 프로덕션 빌드 통과.

## 수정·추가 파일

- `src/service/data/twClimate.generated.ts`: 검증된 두 도시 12개월 정적 수치·관측소·기간·출처.

- `scripts/build_tw_climate.mjs`, `scripts/verify_tw_ui.mjs`: 오프라인 자료 생성과 실제 화면 검증.

- `tests/us-climate.test.mjs`: 미수집 도시 목록에서 새로 지원한 타이베이만 제외.

## 미검증·범위 제한

필수 기온 3종과 강수량·강수일수·상대습도는 두 도시 12개월 모두 확보했다. 해당 표에는 항목별 유효 관측 연수·개별 연도 결측 플래그가 없어 이를 별도로 검증했다고 주장하지 않는다. 공식 표의 게시 평년값을 사용하며 결측 보간은 하지 않는다. 전체 관측소 균질성 재검토·일별 원자료 재계산·바람·자외선·태풍 통계는 범위에 포함하지 않는다. 태국·베트남은 계속 미수집 상태다.
