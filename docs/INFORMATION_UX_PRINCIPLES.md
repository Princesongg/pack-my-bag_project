# PACK MY BAG 공통 정보 안내 UX

적용일: 2026-10-25. 대상 사용자는 전문 지식 없이 해외여행을 준비하는 한국인이다.

## 기본 작성 순서

**정보 → 의미 → 행동**을 연결한다. 실제 자료와 서비스 제안은 구분한다. 행동에 도움이 되지 않는 정보로 물품을 억지로 생성하지 않는다.

- 정보는 숫자·단위·도시 또는 국가·기간·출처를 정확하게 쓴다.
- 의미는 짧은 한국어로 설명한다. 예측이나 확정 허용으로 과장하지 않는다.
- 행동은 사용자가 무엇을 확인하거나 준비해야 하는지 쓴다.
- 국제 타입명·INPUT 같은 표기는 한글 설명과 함께 쓴다.
- 긴 예외·추가 형태·계산 방법은 접이식 영역에 둔다. 글씨를 줄여 끼워 넣지 않는다.

## 전압 안내의 고정 구조

모든 지원 국가의 ElectricityInfo는 같은 네 영역을 같은 순서로 표시한다.

1. 한국 제품을 사용할 수 있나요? — 한국 220V·60Hz와 비교. 개인 기기의 입력 전압을 모르면 사용 가능을 확정하지 않는다.
2. 현지 콘센트는 어떻게 생겼나요? — 한글 형태명과 Type명을 함께 표시. 큰 공통 SVG를 사용한다. 사용 빈도 근거가 없으면 그림 순서를 빈도 순위로 부르지 않는다.
3. 무엇을 챙겨야 하나요? — 같은 위치의 버터 옐로 준비물 영역. 물품별 상태·이유를 표시한다.
4. 주의할 점은 무엇인가요? — 어댑터와 변압기 차이를 먼저 설명하고, 접지·고전력·추가 조건은 펼침으로 둔다.

상단에는 수치와 어댑터 상태·한 줄 행동을 보여줘 긴 내용을 읽기 전 핵심을 파악하게 한다. 국가별 컴포넌트는 만들지 않는다.

## 준비물 상태

| 상태 | 사용 기준 |
| --- | --- |
| 필수 | 실제 여행 조건에 반드시 필요하다는 근거가 확인된 경우만 사용. 이 전압 안내에는 자동으로 부여하지 않는다. |
| 준비 권장 | 호환 형태 준비 등 도움은 되지만 모든 사용자에게 필수라고 할 수 없는 물품. |
| 확인 후 결정 | 숙소·기기 사양·실제 가져갈 물품을 확인해야 하는 경우. |

팝업과 MY BAG은 getElectricityPreparation의 같은 ID·명칭·상태·이유를 읽는다. 충전기·케이블은 `electronic:charger`, 어댑터는 기존 `electronic:travel-adapter`를 사용한다. 변압기·드라이어·고데기는 제품 조건이 없어 자동 항목을 생성하지 않는다.

기존 사용자 어댑터의 ID와 저장 상태는 유지한다. 별칭으로 추가된 어댑터는 화면에서 공통 명칭으로 표시하지만 저장된 사용자 이름을 덮어쓰지 않는다. 체크·제외·복원은 기존 기능을 사용한다. 추천 변경이 사용자 선택을 자동 취소하지 않는다.

## 전기 호환 판단 원칙

전압·주파수·플러그 모양·필요한 접지·허용 전력을 각각 확인한다. INPUT 100–240V, 50/60Hz는 제품 라벨 확인 예시이며 모든 기기가 이 조건이라고 가정하지 않는다. 어댑터는 모양만, 변압기는 전압을 바꾸며 주파수 문제까지 해결하는 것으로 안내하지 않는다. 핀 모양이 비슷해도 기계적 호환이나 접지를 보장하지 않는다.

## 출처와 검증

목적지 사실의 출처는 국가별로 변경한다. 한국 220V·60Hz 비교 출처는 별도 영역으로 구분한다. 자료를 제공한 조직의 소재지가 아니라 실제 해당 정보를 설명하는지를 판단한다. 예를 들어 JMA의 세계 기후 자료는 베트남 기후 출처로 쓸 수 있지만, JNTO 일본 전기 자료를 미국 전기 출처로 쓰면 안 된다.

getElectricityGuide는 원본 Evidence·출처 ID·출처 상태·확인일·URL을 검사한다. 출처가 없거나 미확인·확인일 누락이면 공식 확인 필요로 처리하고 확정 안내·그림·전기 기반 자동 준비물 생성을 막는다. 과거 확인일을 일괄 현재 날짜로 바꾸지 않는다.
