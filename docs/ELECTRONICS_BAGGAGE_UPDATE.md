# 전자기기 항공 반입 안내 개선

실제 자료 확인일: **2026-10-25**

전자기기 상세 영역을 `전자기기 · 항공 반입 안내`로 바꾸고 다음 순서로 정리했다.

1. 노트북 · 태블릿 · 게임기 — **기내 휴대 권장**. 카메라·스마트폰 포함. 조건부 위탁 확인과 완전 종료·손상 방지, 슬립·절전 모드와의 차이를 기본 카드에 표시한다.
2. 보조배터리 · 여분 리튬배터리 — **기내만 가능 / 위탁 금지**. 단자 보호와 보조배터리 최대 2개, 국토교통부 기준의 기내 사용·자체 충전 금지를 명시한다.
3. 전자담배 · 특수 배터리 — **별도 규정 확인**. 허용 시 기내만 휴대, 위탁·기내 사용·충전 금지. 국가·항공사 반입 제한과 의료·습식배터리 별도 조건을 안내한다.

용량·승인·예외와 출처별 차이는 기본 닫힘 상태의 **추가 확인 사항**에 배치했다. 아이보리·블루·버터 옐로 색상을 유지한다. 일반 안내이며 특정 운송인의 승인이 아님을 표시하고 국가 선택으로 항공사 규정이 자동 결정되지 않는다고 설명한다.

## 공식 자료 대조

| 항목 | 확인 결과와 반영 |
| --- | --- |
| 내장 리튬이온 배터리 | 일반적인 100Wh 이하 기준과 100Wh 초과~160Wh 이하의 항공사 승인 요건을 구분. 모든 기기를 위탁 가능 또는 금지로 확정하지 않음. |
| 기기 위탁 | IATA 2026 PDF 7–8쪽은 조건부 위탁 시 완전 종료·손상·우발 작동 방지를 설명. 여행객 웹 페이지는 기내 휴대를 강조하는 보수적 문구를 사용하므로 두 안내의 차이도 표시. |
| 보조배터리 용량 | IATA 2026 PDF Table 1은 최대 2개·각 100Wh 이하, 100Wh 초과~160Wh 이하 금지. 국토교통부 4월 발표는 최대 2개·각 160Wh 이하 표현. 단일 160Wh 허용 상한을 공통 데이터에 두지 않고 실제 항공사·국가별 용량과 승인 가능 여부를 확인하도록 처리. |
| 보조배터리 사용·충전 | 국토교통부는 사용·자체 충전 전면 금지, 한국 기준 2026-04-20 시행. IATA 2026 PDF는 자체 충전 금지 및 다른 기기 전원 공급의 지상 이동·이륙·착륙 중 금지를 설명. 이 적용 차이를 구분. |
| 여분 배터리 | 보조배터리와 다른 분류. 모든 여분 배터리에 최대 2개 규칙을 일괄 적용하지 않음. 분리 배터리 위탁 금지·개별 단락 방지와 별도 용량·승인 조건 안내. |
| 큰 배터리·특수 장비 | 160Wh 초과 일반 보조배터리를 여객 수하물로 안내하지 않음. 의료·이동보조기기 등의 예외는 별도 확인으로 유지. |

확인한 공식 출처:

- [IATA 2026 승객용 리튬배터리 지침](https://www.iata.org/contentassets/6fea26dd84d24b26a7a1fd5788561d6e/passengers_travelling_with_lithium_batteries.pdf): 2026-03-31 개정본의 7쪽과 8쪽 Table 1.
- [IATA 여행객 배터리 안전 안내](https://www.iata.org/en/youandiata/travelers/batteries): 기내 휴대·전자담배·국가 및 항공사별 제한.
- [국토교통부 2026-04-08 발표 · 정부 공식 정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148962298): 용량 표현·수량·충전 및 사용 금지·한국 시행일.

요청된 [국토교통부 원문](https://www.molit.go.kr/USR/NEWS/m_71/dtl.jsp?id=95091874)은 반복 리디렉션으로 이번에 직접 재확인하지 못했다. 따라서 실제로 읽은 정부 공식 정책브리핑 게시본을 팝업의 확인 출처로 사용했다. 원문을 읽은 것으로 확인 날짜를 갱신하지 않았다. 세 출처 이름·실제 확인 날짜는 펼침 없이 전자기기 안내 하단에 표시한다.

## 변경 범위

- `src/service/data/electronicsGuidance.ts`: 세 카드·추가 확인 사항·출처·확인일을 한 곳에 정의.
- `src/service/data/baggageRules.ts`: 전자기기 및 보조배터리만 새 안내를 공통 사용. 공통 보조배터리 요약의 단정적인 `각 160Wh 이하` 문구와 무조건적인 Wh 최대값 제거. 다른 반입 품목 데이터는 유지.
- `src/service/data/sources.ts`: IATA 2개 출처 등록, 실제 확인한 정책브리핑 게시본의 확인일·한계 기록.
- `src/service/travel-info/BaggageGuide.tsx`, `ElectronicsGuidance.tsx`, `ElectronicsGuidance.css`: 기존 상세 패널 안에 공통 컴포넌트 표시. 기존 모달 닫기·포커스 복원 유지.
- `tests/baggage-rules.test.mjs`: 용량 차이·분류·종료 조건·출처 검증 추가.
- `scripts/verify_electronics_ui.mjs`, `docs/verification/electronics/`: 실제 화면 검증 및 증빙.

기후·여행 데이터, 체크리스트 구조, 수하물 선택, RED FLAGS 상태 저장, LAST MINUTE BAG 로직은 변경하지 않았다. 새로운 외부 API·인증·과금 서비스는 없다.

## 검증 결과

- 실제 여행 입력 → MY BAG 생성 → 항공 수하물 모달 → 전자기기 상세 경로 통과.
- **1440px / 390px / 320px**에서 세 카드 순서·배지·추가 확인 펼침·출처 확인일·닫기 후 포커스 복원 확인. 페이지·모달·카드 가로 넘침 없음.
- 일본/위탁 포함, 대만/기내수하물만 선택에서도 일반 안내가 임의로 달라지지 않음.
- PACKING RED FLAGS의 항공 반입 영역에서도 같은 전자기기 안내 표시. LAST MINUTE BAG 진입 정상.
- 브라우저 예외 0건, 검증 중 외부 요청 0건.
- 전체 테스트 **61개 통과**, TypeScript 및 Vite 프로덕션 빌드 통과.
