# STEP 04-2 — TRAVEL INFO 화면

## 진입과 기존 화면 유지

- 신규 경로: `/implementation/travel-info`.
- TRIP DETAILS의 NEXT는 기존 유효성 검사를 통과한 후 저장을 시도하고 이 화면으로 이동한다.
- 여행지가 없으면 DESTINATION, 일정·목적·수하물이 미완성이면 TRIP DETAILS로 돌아간다.
- PREVIOUS는 TRIP DETAILS로 돌아가며 기존 `TripContext`의 선택 정보는 유지된다.
- HOME·Planning·DESTINATION 및 기존 CSS는 수정하지 않았다. TRIP DETAILS는 NEXT 연결 및 설명만 갱신했다.
- 헤더의 `currentPage="travel-info"`는 이 화면에서만 TRAVEL INFO를 현재 메뉴로 표시한다. 기존 화면의 헤더는 기존 출력 그대로다.
- 화면과 기후 자료는 지연 로딩한다. 기존 화면에 새 CSS를 적용하지 않고 `.pmb-guide-service` 범위에서만 사용한다.

## 데이터 연결

기존 `src/service/data/`의 자료와 함수는 수정하지 않았다.

- `getTripClimate(cityId, departureDate, returnDate)`를 호출해 월·연도를 보존하는 여행 구간을 받는다.
- 두 달 이상이면 각 월 선택 버튼으로 전환한다. 월별 체류 일수는 기후를 일별 예보로 환산하는 데 사용하지 않는다.
- 월평균 기온, 일최고/일최저 기온의 월평균, 월강수량 평균은 `recommendedMetrics`를 사용한다.
- 각 항목에 실제 적용된 2016–2025 관측 평균 또는 1991–2020 공식 평년값의 기준을 표시한다.
- 화면 표시 수치는 소수 첫째 자리로 반올림한다. 원본·계산값·품질 상태는 수정하지 않는다.
- 공식 30년 평년값은 별도 참고 영역에 표시한다.
- 모든 출처 링크는 기존 `getSource()`에서 가져오며 확인일·자료 기준을 함께 제공한다.
- 전압/주파수/Type A 도식, 통화/시간대, 공식 입국 서비스도 기존 자료만 사용한다.

## 확인 필요 항목의 표시

- 현재 수치 데이터는 일본의 도쿄·오사카·후쿠오카·삿포로만 지원한다.
- 베트남·태국·대만에는 다른 국가의 값을 대신 넣지 않고 `공식 정보 확인 필요`를 표시한다.
- 관측소의 전체 이전·관측 환경·통계 단절 이력 검토가 완료되지 않았음을 안내한다.
- 월별 정성적 계절 특징은 자료 상태를 확인한다. 삿포로의 겨울 특징은 정성적 도시 특징으로 표시하며 다른 달의 실제 강설 예측으로 사용하지 않는다.
- 입국 기본 조사 조건은 한국 일반여권·단기 관광이다. 출장·업무 또는 조사 범위의 체류 기간을 초과하는 일정에는 관광 사증 면제 기준을 판정처럼 표시하지 않는다.
- Visit Japan Web의 기능은 확인된 설명을 표시하되 전원 의무 서비스라고 안내하지 않는다. 세부 적용 조건과 여권 잔여 기간은 공식 확인이 필요하다.

## 옷차림

기존 `clothingPolicy.enabled`는 여전히 `false`다. 조사 단계의 비활성 초안을 확정 추천으로 바꾸지 않는다.

`guideModel.ts`는 기존 `clothingRules` 조건과 해당 월의 기후값에 일치하는 **검토용 후보**만 만든다. 공식 기관의 권장 복장과 구분하여 PACK MY BAG의 제안임을 표시한다. 후보마다 이유·조건·권장/선택 후보·`checklistItemId`를 유지한다.

- 기후값이 없거나 통계 기준이 섞이면 후보를 만들지 않는다.
- 일교차 조건에서도 서로 다른 기간의 최고·최저 기온을 섞지 않는다.
- 계절 정보·최신 예보·개인 활동 검토 전 확정 추천이 아니라는 안내를 표시한다.
- 체크박스, 준비물 자동 생성, MY BAG 저장 및 실제 체크리스트는 구현하지 않았다.

## BAGGAGE GUIDE

기존 자료는 항공 규정의 구조만 제공하고 실제 허용량·판정은 미확인이다. 따라서 새 가상 규정 화면으로 연결하지 않는다.

TRAVEL INFO 하단의 BAGGAGE GUIDE 링크는 같은 페이지의 공식 안내 연결 영역으로 이동한다. 기존 `baggageRules`의 7개 확인 범주 및 미확인 상태, 인천국제공항 공식 링크를 보여준다. 한국 출발 기준 링크임을 명시하고 항공사·노선·환승국·다른 출발국의 적용 조건 확인을 안내한다.

- 미지원 국가의 기온·옷차림·일본 통화·전압 미노출 확인.
