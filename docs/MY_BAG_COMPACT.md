# MY BAG RESULT — 반응형 요약 및 체크리스트 압축

2026-10-25. 기존 데이터·저장 스키마·체크리스트 ID·상세 모달·애니메이션 로직을 유지한 로컬 UI 수정입니다. Production 배포는 하지 않았습니다.

## 원인과 적용

- 상단의 단계/영문 보조 라벨·한글 제목이 반복되고, 여행 카드의 시각이 독립된 큰 블록으로 표시됐음.
- 모바일에도 큰 콘센트 SVG와 설명을 가진 카드가 모두 쌓였고,5개 체크리스트 카테고리 전체가 열려 있었음.
-640px 이하에서 중복 보조 제목만 숨기고 Ready to pack?와 간결한 안내 유지. 기존 메뉴와 여행 정보는 유지.
- 여행 정보 변경 링크를 동일 DOM의 요약 래퍼 안에 배치. PC는 `display:contents`로 기존 위치·기하 유지, 좁은 화면은 노란 카드 안에 링크 표시. 현재 시각과 시차는 하단의 유연한 Flex 행으로 표시.
- TRIP BRIEF는 아이콘/제목/수치·조건/오른쪽 화살표의 요약 Grid. 카드 전체 클릭과 키보드 button 동작 유지. 전압·주파수·타입·어댑터 안내 및 항공 기내만 가능/위탁 금지·개수/조건·허용량 확인 안내는 남김.
- 큰 콘센트 SVG는 모바일 요약에서 접고 기존 전압 모달에는 그대로 유지. 중요한 상세 내용은 삭제하지 않음.
- RED FLAGS는 제목·미확인 영역 수·여권/결제/항공 칩·점검 버튼·개인 확인이라는 안내를 유지. 중복 한글 제목/설명만 모바일에서 축약. 미확인 위험을 완료 처리하지 않음.
- 체크리스트는640px 이하에서 아코디언. 기본은 첫 미완료 카테고리만 열림. 여러 카테고리를 함께 열 수 있고, 헤더에 항상 완료/전체 개수와 펼치기/접기 표시.
- 카테고리 열림 상태는 별도 React UI state이며 BagState나 localStorage에 추가하지 않음. 접힌 목록도 DOM과 데이터는 유지하고 표시만 접음. PC·태블릿은 모든 목록을 표시.
- 사용자 물품을 추가하면 해당 카테고리를 펼쳐 바로 보이게 함. 물품 행은 최소48px, 긴 설명은 자연스럽게 늘어남. 기존 긴 영문 줄바꿈·삭제 버튼44px 유지.

동일한 일본 도쿄 /2027-11-17~11-20/관광/위탁 포함/체크0개, viewport390×900, Chrome. 개별 섹션과 페이지 전체를 DOM으로 측정했습니다.

전체1,428px(약32.3%) 감소. 여행 정보 본문 수치는 편집 링크/래퍼를 제외한 `.pmb-bag-trip` 영역으로, 새 카드 전체 높이를170px라고 뜻하지 않습니다. 전체 페이지 비교에는 편집 링크와 래퍼 모두 포함됩니다. 목적지·추천·체크 상태·펼침 상태에 따라 길이는 달라지며, 실사용 스와이프 횟수/입력 시간 측정은 아닙니다.

PC1920/1440/1280px, 태블릿1024/820/768px 및641px에서는 초기 페이지 전체 높이와 측정한 주요 섹션 높이가 변경 전후 동일했습니다.3열/2열 기존 카드와 펼친 체크리스트 구조를 유지했습니다.
