# 태국 전압 안내 문구 정리

확인일: 2026-10-25

태국의 안내 문구와 준비물 표시만 수정했다. 220V·50Hz, C/O 그림과 원본 전기 규격, 국가별 기후·입국·항공 규정·저장 모델은 변경하지 않았다.

## 적용

- `electricityGuide.ts`: 태국 전용 사용 안내·드라이어 주의 문구와 3개 준비물의 상태/이유를 정의했다.
- 충전기 · 케이블: 챙기기. 기존 `electronic:charger` 사용.
- 여행용 변환 어댑터(돼지코): 준비 권장. 기존 `electronic:travel-adapter` 및 사용자가 저장한 어댑터 ID를 재사용한다.
- 드라이어 · 고데기: 확인 후 결정. 별도의 기본 항목을 자동 생성하지 않는다. 기존 사용자 준비물은 그대로 유지하며 숙소 비품 여부·50Hz 지원·소비전력 확인을 안내한다.
- `ElectricityInfo.tsx`: 베트남과 같은 기존 정보 구조를 사용하되 태국 문구를 선택한다. 중복되는 드라이어 일반 설명은 추가 주의 영역에서 제외했다.
- `ElectricityInfo.css`: 베트남 이름이 붙어 있던 블루/옐로 클래스명을 공통 이름으로 변경했다. 기존 색상·패딩·크기는 그대로이며 새 디자인은 추가하지 않았다.

충전기 입력 사양은 “휴대폰·태블릿·노트북 충전기에 INPUT 100–240V · 50/60Hz라고 적혀 있다면”이라는 조건으로 안내한다. 플러그가 맞는 것만으로 전기적 호환·접지를 보장하지 않는다. 드라이어의 50Hz·허용 전력·불안정한 연결·과열/손상·제조사/숙소 확인을 별도 옐로 영역에 정리했다. 변환 어댑터가 전압·주파수를 바꾸지 않는다는 안내를 유지한다.

준비물 이름·상태·짧은 이유는 MY BAG의 기존 추천 조회에서도 같은 값을 사용한다. 데이터 연결 방식에 대한 설명은 사용자 화면에 추가하지 않았다.

## 검증

- 베트남·일본·대만·미국·호주 안내 객체를 수정 전 스냅샷과 비교: 모두 동일.
- 자동 테스트 83개 통과. 준비물 상태/이유 연결, ID 중복 방지, 기존 사용자 체크·제외 복원 포함.
- TypeScript 및 Vite 빌드 통과.
- `scripts/verify_th_electricity_copy_ui.mjs`: 태국 3개 도시 × 1440/390/320px = 9개 시나리오 통과.
- 한국 충전기 조건·숙소 차이·드라이어 주의·준비물 3가지 상태·블루/옐로 영역·C/O 실제 핀 구조·그림 크기·출처 혼입 없음·모달 넘침 없음 확인.
- 어댑터 체크 새로고침 유지·제외/복원, 항공안전 모달 유지 확인. 브라우저 예외·외부 런타임 요청 없음.
- 화면과 결과: `docs/verification/th-electricity-copy/`.

## 출처 대조

기존 공식 출처를 유지했다. 태국관광청 https://www.tourismthailand.org/Articles/plan-your-trip-electricity 의 전압·주파수·시설별 형태·접지/전력·60Hz 기기의 50Hz 사용 주의를 다시 확인했다. 태국 정부 행사 안내 https://www.am2026thailand.go.th/electrical-info-and-devices 의 220V·50Hz 및 C/O·A/B/F 설명도 대조했다. 개별 제품의 안전성을 이 국가 자료만으로 확정하지 않는다.

유료·종량제 API, 새 서버, 외부 이미지 연동은 추가하지 않았다.
