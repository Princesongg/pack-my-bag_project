# PACKING RED FLAGS

- 목적: 물품 준비 여부와 별개로 사용자가 출발 전 실제 사용 조건을 직접 점검하도록 돕는다. 입국·결제·반입 가능 판정 기능이 아니다.
- UI: YOUR TRIP BRIEF 아래 배너 → 공통 `ServiceModal` → 여권/결제/항공 반입 영역 선택. 체크리스트의 여권·결제 항목에서도 해당 영역을 열 수 있다.
- 점검: 여권 5개, 결제 5개, 항공 4개. 각 영역의 모든 항목을 직접 체크한 경우에만 해당 영역을 ‘확인 완료’로 집계한다. 준비물 진행률과 분리한다.
- 저장: 기존 `pack-my-bag.bag.v1:<여행 조건 배열>` JSON에 `redFlagCheckedIds?: string[]`만 추가한다. 기존 체크·사용자 물품·PACK LESS는 유지한다. 복원 시 허용된 점검 ID만 남기고 중복·미등록 ID를 제거한다.
- 여권 만료일: 모달의 React 상태에서만 보관하며 모달 닫기/새로고침 시 폐기한다. 날짜는 기존 UTC 날짜 계산 함수로 비교한다. 여행 종료일과 같거나 이후여도 입국 가능 여부를 보증하지 않는다. 국가별 잔여 유효기간 숫자를 임의로 적용하지 않는다.
- 입국 출처: 기존 일본 `entryGuides.JP` 및 출처/확인일 재사용. 미검증 국가는 외교부 해외안전여행에서 국가별 공식 조건을 직접 확인하도록 연결한다. 새로운 국가별 입국 기준은 추가하지 않았다.
- 항공 출처: 기존 `BaggageGuide` 및 검증된 규정·출처·확인일 재사용. 수하물 유형은 관련 점검 안내를 강조하는 데만 사용한다.

## 해외 결제 안내 확인

실제 확인일: **2026-10-23**. 카드 정보·카드사 앱 상태는 수집/조회하지 않는다. 아래 안내는 서로 다른 설정을 설명하며, 특정 카드의 사용 가능 여부를 확정하지 않는다.

- [KB국민카드: 해외거래정지 등록·해제](https://mapps.kbcard.com/SVC/DVIEW/HSDMCXPRISVCD0029): 해외 거래 사용 전 해제 필요, 국내 이용과 별도인 설정임을 확인.
- [BC카드: 해외원화결제(DCC) 차단](https://www.bccard.com/app/card/BcnewsViewActn.do?newsurl=%2Fcard%2Fhtml%2Fetc%2Fnotice%2F1203858_21560.jsp): 해외 가맹점의 원화(KRW) 결제에 대한 이용/제한 설정임을 확인. DCC 차단만으로 해외 결제 전체 불가로 판단하지 않도록 명시.

카드번호·CVC·비밀번호·여권번호·생년월일 입력란은 없다. 수수료율, 한도, 카드 상태 등 개인별 미확인 수치는 표시하지 않는다.
