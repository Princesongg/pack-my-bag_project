# 미국·호주 지원 범위

실제 확인일: **2026-10-23**. 외부 API 없이 정적 자료와 브라우저 Intl/IANA 시간대 데이터를 사용한다.

## 선택 및 체크리스트

- 미국 `US`: 뉴욕 `new-york`, 로스앤젤레스 `los-angeles`
- 호주 `AU`: 시드니 `sydney`, 멜버른 `melbourne`
- 국가·도시 검색, 여행 날짜·목적·수하물, 여행별 저장 키, MY BAG 기본 목록·진행률·사용자 물품, PACK LESS, PACKING RED FLAGS 지원.
- 카드 목록은 기존 4개국을 포함한 6개국의 단일 목록이며 2열 × 3행이다.

## 확인한 정보

- [미국 에너지부 Electricity 101](https://www.energy.gov/oe/electricity-101): 110–120V, 60Hz 및 2핀·3핀 안내. 본문이 제공하는 형태 설명을 사용하며 확인하지 않은 규격명을 추가하지 않는다. 시설·접지·기기 대응 여부는 별도 확인.
- [미국 통화교육프로그램](https://www.uscurrency.gov/): 미국 달러. 환율·결제 가능 여부는 제공하지 않는다.
- [미국 국무부 VWP](https://travel.state.gov/content/travel/en/us-visas/tourism-visit/visa-waiver-program.html): ESTA는 VWP 자격에 따른 제도이며 국적·여권·목적·여행 이력 등에 따라 다른 비자가 필요할 수 있다. 승인이나 입국을 보장하지 않는다.
- [호주 관광청 Key Facts](https://www.australia.com/en/facts-and-planning/about-australia/key-facts-about-australia.html): 220–240V, 50Hz, 역 V자 평핀 및 일부 중앙 핀, 호주 달러. 어댑터가 전압을 바꾸지 않는 기존 안내도 유지한다.
- [호주 정부 Visa FAQs](https://usa.embassy.gov.au/visa-faqs): ETA와 다른 비자 선택을 위한 공식 안내. 국적·목적·자격별 확인이 필요하며 모든 사용자에게 ETA를 일괄 필수로 안내하지 않는다.
- [미국 NIST 시간대 안내](https://www.nist.gov/pml/time-and-frequency-division/local-time-faqs), [호주 관광청 시간대 안내](https://www.australia.com/en/facts-and-planning/about-australia/time-zones.html): 뉴욕·로스앤젤레스·시드니·멜버른의 IANA 시간대별로 날짜마다 UTC 정오의 오프셋을 계산한다. 여행 중 DST 전환 시 두 시차를 모두 표시한다. 항공편 출도착 시각 변환이나 미래 법령 확정을 뜻하지 않는다.

## 기후·옷차림: 아직 미지원

- [NOAA NCEI Climate Normals](https://www.ncei.noaa.gov/products/land-based-station/us-climate-normals): 공식 1991–2020 평년값 자료 안내를 확인했다. 새 두 도시의 관측소·기후 수치·품질 검증은 완료하지 않았다.
- [BOM Climate Data Online](https://www.bom.gov.au/climate/data/): 공식 조회 경로를 확인했다. 새 두 도시의 관측소·기간·수치·품질 검증은 완료하지 않았다.
- 네 도시의 2016–2025 월별 평균, 공식 평년값, 기후 기반 옷차림 후보는 null/확인 필요로 유지한다. 기존 일본 수치나 다른 도시로 대체하지 않는다.
- 자료 안내 페이지의 확인일은 도시별 기후 수치 검증 완료일이 아니다. BOM의 관측소별 관측기간을 임의로 NOAA의 1991–2020 또는 기존 일본의 2016–2025로 표기하지 않는다.
- 준비물은 기본 목록과 직접 추가 기능을 제공하며, 검증된 기온이 없으므로 자동 기후 의류 항목을 생성하지 않는다.
- 국가별 여권 잔여 유효기간, 개별 ESTA/ETA 자격 판정, 체류·근로 권한 등 미확인 세부 조건은 공식 안내를 직접 확인하도록 유지한다.

기존 한국 출발 국제선 BAGGAGE GUIDE는 공통으로 재사용한다. 미국·호주 출발/귀국편의 별도 규정이나 항공사 수하물 허용량으로 확대 해석하지 않는다.
