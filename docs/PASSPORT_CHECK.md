# PASSPORT CHECK 국가별 유효기간 판정

공식 자료 확인일: 2026-10-25

## 변경 범위

기존 `passportDateNotice`는 여행 종료일과 만료일만 비교했다. 이를 제거하고 `passportRules.ts`의 국가별 정적 기준과 `passportModel.ts`의 날짜 계산을 `PassportCheck.tsx`에서 사용한다. 출처는 기존 `sources.ts`와 SourceLinks에 연결했다. 결제·항공 반입 체크 및 MY BAG 저장 형식은 변경하지 않았다.

국가·도시는 기존 여행 정보를 사용한다. 여권 번호나 사진은 받지 않는다. 만료일·적용 범위 확인·경유 조건은 PassportCheck의 React 상태에만 보관하며, 탭 이동·모달 닫기·새로고침 시 폐기한다. 국가·일정·방문 목적 변경 시 컴포넌트 key로 재설정하여 다른 여행에 재사용하지 않는다. 체크리스트에서 사용자가 직접 확인한 항목 ID만 기존대로 저장한다.

## 기준과 판정

| 국가 | 한국 일반여권 단기 관광 기본 비교 |
|---|---|
| 일본 | 여행 종료일까지 유효. 별도 최소 6개월 요구 없음 |
| 베트남 | 일반 무비자 입국일 + 달력 6개월. 한국 대상 정책 적용기간 및 45일 범위도 확인 |
| 태국 | 입국일 + 달력 6개월 |
| 대만 | 한국 일반여권 무비자 입국일 + 달력 6개월 |
| 미국 | 한국 여권 추가 6개월 면제, 예정 체류 종료일까지 유효. ESTA 등은 별도 |
| 호주 | 예정 체류 종료일까지 유효. 항공사·경유 국가·ETA 등은 별도 |

6개월은 180일로 바꾸지 않는다. 같은 일자의 여섯 달 뒤 날짜를 계산하고, 해당 날짜가 없는 달은 마지막 날로 맞춘다. 예: 2026-08-31 → 2027-02-28, 2027-08-31 → 2028-02-29. 날짜만 UTC로 처리하므로 시간대·서머타임에 영향을 받지 않는다. 여권은 6개월 기준뿐 아니라 여행 종료일까지도 유효해야 한다.

여행 시작일을 현지 입국일로 사용하는 점을 화면에 명시했다. 야간·경유 항공편 등으로 실제 입국일이 다르면 여행 날짜를 실제 일정에 맞춰 확인하도록 안내한다.

한국 일반여권·단기 관광·일반 무비자 기준 적용 여부는 체크박스로 확인한다. 미확인 또는 출장·업무이면 추가 확인 상태다. 날짜 기준이 맞아도 경유 여부가 미확인이면 추가 확인 상태다. 적용 범위가 확인되고 날짜가 부족하면 빨간색 기준 미달로 표시한다. 직항 또는 경유지 요건 확인까지 선택한 경우에만 기본 날짜 조건 충족으로 표시한다. 입국 허가는 보장하지 않는다.

공식 출처가 미검증·미기록·누락되면 확정 판정하지 않는다. 베트남 정책의 확인된 적용기간(2025-03-15~2028-03-14) 또는 45일 범위를 벗어나면 일반 무비자 날짜 판정을 확정하지 않는다. 푸꾸옥 특별면제나 비자 입국에 일반 무비자 규칙을 자동 확대하지 않는다.

- 태국: https://www.tourismthailand.org/Articles/plan-your-trip-customs-and-immigration — 입국 시 여권 최소 6개월. 해당 페이지의 체류 허용일수는 판정에 사용하지 않았다.
- 대만: https://www.boca.gov.tw/cp-149-4486-7785a-2.html — 한국 무비자 대상, 입국일 기준 6개월. 미국·일본 국적 예외와 구분.
- 미국: https://fam.state.gov/FAM/09FAM/09FAM040309.html — 직접 내려받은 공식 HTML에서 9 FAM 403.9-3(B)(1)/(2), 2025-03-26 개정 목록의 South Korea 확인. 요청된 CBP URL https://www.help.cbp.gov/s/article/Article-1238?language=en_US 은 검색 본문에 체류기간 유효 조건이 있으나 직접 열면 CSS 오류여서 독립 확정 근거로 쓰지 않았다. 추가 공식 링크에는 본문 재확인 필요 상태로 남겼다. 구형 2022 PDF만으로 현재 기준을 확정하지 않았다.
- 호주: https://singapore.embassy.gov.au/sing/visas-faq.html — 별도 6개월 요구 없음, 입출국 시 유효 여권, 항공사·다른 국가 조건 확인.

이 정적 데이터는 런타임에 공식 사이트를 자동 재조회하지 않는다. 규정 변경 시 근거·확인일·상태를 재검토하여 갱신해야 한다. 유료 API·새 서버·DB는 추가하지 않았다.
