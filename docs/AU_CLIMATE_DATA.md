# 호주 기후 데이터와 실제 화면 연결

실제 자료 확인일: 2026-10-23 (Asia/Seoul). 새 API·페이지·CSS 변경 없이 기존 조회/추천/모달을 재사용한다.

## 공식 원문

- [BOM Sydney Airport AMO / 066037](https://www.bom.gov.au/climate/averages/tables/cw_066037_All.shtml)
- [BOM Melbourne (Olympic Park) / 086338](https://www.bom.gov.au/climate/averages/tables/cw_086338_All.shtml)

두 페이지의 All years of record 표에서 Mean maximum temperature, Mean minimum temperature, Mean rainfall 행을 추출했다. 원본 HTML과 URL·확인일·SHA-256·추출 행은 `src/service/data/raw/au/`에 저장했다. 원문은 분기별로 갱신될 수 있으므로 이후 다운로드와 저장본을 구분해야 한다.

| 도시 | 기온 범위 | 최고/최저 가용 연수 | 강수 범위 | 강수 가용 연수 | 관측소 개설 |
|---|---|---|---|---|---|
| 시드니 공항 | 1939–2026 | 88년 / 87년 | 1929–2026 | 93년 | 1929년 |
| 멜버른 Olympic Park | 2013–2026 | 13년 / 13년 | 2013–2026 | 11년 | 2013년 |

원문의 시작·끝 연도와 Years of available data를 그대로 구분했다. 범위 내 모든 연도/월에 결측이 없거나 2026년 전체가 완료됐다는 의미가 아니다. 일본의 2016–2025 평균이나 미국의 1991–2020 평년값으로 표시하지 않는다.

## 수치 및 조회 연결

- `auClimate.ts`: `sydney`, `melbourne`의 12개월 최고·최저·강수량 및 관측소·항목별 기간·가용 연수.
- `getTripClimate()` → `getClimateMonth()` → `getAUClimateMonth()` → SMART TRIP BRIEF / WeatherGuide / `getClothingPreview()` / `getDefaultBagItems()`.
- 공식 최고·최저·강수의 `basis`는 `all-years-of-record`다.
- 평균기온은 `(평균 최고 + 평균 최저) / 2`, 소수 첫째 자리 반올림의 서비스 참고값이다. `basis: derived-high-low-midpoint`이며 카드 제목·보조 문구·날씨 포인트·출처 설명에서 계산값임을 표시한다. 반올림 경계 오차를 막기 위해 소수 한 자리 입력을 정수 10분위로 처리한다.
- 옷차림은 기존 온도 조건을 사용한다. 강수 기반 규칙은 강수 자체의 기록 기간을 가진 독립 조건으로만 검토하며, 기온과 같은 표본 기간이라고 가정하지 않는다.
- 남반구 계절은 월에 따라 여름/가을/겨울/봄을 표시한다. 계절명만으로 의류를 결정하거나 자외선·강설·습도·바람·실제 예보를 생성하지 않는다.
- 후보와 MY BAG에는 기존 checklistItemId를 사용해 다달이 중복되는 물품을 합친다. 기존 저장 키·체크·PACK LESS·RED FLAGS·LAST MINUTE 상태는 초기화하지 않는다.

## 제공 표와 현재 원문 차이

현재 확인한 BOM 원문이 요청문의 표와 일부 다르다. 검증된 공식 수치 연결이라는 목적에 따라 현재 저장한 원문을 적용했다. 특히 요청 시나리오 B는 시드니 최저 7.4가 아닌 **7.5°C**, D는 멜버른 최저 7.5가 아닌 **7.6°C**다. 이는 임의 보간이나 반올림 변경이 아닌 BOM 표의 값이다.

아래 항목만 요청문의 표와 다르며, 나머지는 일치한다.

| 도시·항목 | 월 | 요청 표 → 원문 적용값 |
|---|---|---|
| 시드니 최고 | 2 | 26.5 → 26.6 |
| 시드니 최저 | 5 / 7 | 11.1 → 11.2 / 7.4 → 7.5 |
| 시드니 강수 | 2 / 4 / 6 / 7 | 117.6 → 117.2 / 107.8 → 107.1 / 124.1 → 123.6 / 72.5 → 72.3 |
| 시드니 강수 | 8 / 9 / 10 / 11 | 77.6 → 77.3 / 60.4 → 60.3 / 70.7 → 70.8 / 80.6 → 80.7 |
| 멜버른 최고 | 4 / 6 / 9 | 20.8 → 20.9 / 14.7 → 14.9 / 18.0 → 18.1 |
| 멜버른 최저 | 5 / 6 / 7 / 8 | 9.7 → 9.8 / 7.7 → 7.8 / 7.5 → 7.6 / 8.0 → 8.1 |
| 멜버른 강수 | 2 / 3 / 4 / 5 | 24.7 → 26.3 / 34.5 → 36.4 / 66.7 → 63.0 / 46.3 → 46.5 |
| 멜버른 강수 | 6 / 7 / 8 / 9 | 41.3 → 42.1 / 40.8 → 41.0 / 45.6 → 47.0 / 42.7 → 41.0 |

## 실제 브라우저 검증

각 조건은 기존 TRIP SETUP에서 국가·도시·날짜·목적·수하물을 선택하고 MAKE MY BAG을 눌러 결과를 생성했다. localStorage에 여행 조건을 주입하는 방식이 아닌 실제 폼 조작으로 확인했다.

| 조건 | 평균 참고값 / 최고 / 최저 °C | 기존 추천 예 | 결과 |
|---|---|---|---|
| A 시드니 2027-01 | 22.9 / 26.8 / 19.0 | 반팔 | 통과 |
| B 시드니 2027-07 | 12.4 / 17.2 / 7.5 | 얇은 외투·겹옷 | 통과 |
| C 멜버른 2027-01 | 21.7 / 26.8 / 16.5 | 가디건 | 통과 |
| D 멜버른 2027-07 | 11.1 / 14.5 / 7.6 | 니트·얇은 긴팔 | 통과 |
| E 시드니 2026-12 → 2027-01 | 21.9 / 26.0 / 17.7 → 22.9 / 26.8 / 19.0 | 월별 전환·ID 중복 없음 | 통과 |
| F 뉴욕 2027-01 | 0.9 / 4.2 / -2.3 (공식 평년값) | 겨울 외투 | 통과 |

각 시나리오에서 PC 1440px와 모바일 375/390/430px의 모달 기온·추천·공식 링크·가로 넘침을 확인했다. 기존 의류 카드/모바일 칩 디자인을 유지했다. 멜버른 7월은 기존 임계값상 니트·긴팔 후보이며 최저 5°C 이하일 때의 겨울 외투 규칙을 강제로 적용하지 않았다.

## 테스트와 남은 범위

- `au-climate.test.mjs`: 24개월 값과 원본 HTML 3행 직접 대조, SHA-256, 항목별 기간/연수, 계산값 표시, 남반구 계절, 추천, MY BAG ID 중복, 연도 경계, 미국·일본 회귀 검사.
- 기존 호주 미지원 기대값만 새 지원 범위로 갱신했다. 미확보 베트남·태국·대만 등의 빈 상태는 유지한다.
- 전체 단위 테스트 54개 및 TypeScript/Vite 빌드 통과.
- 고정 30년 평년값, 2016–2025 평균, 강설·습도·바람·UV 수치, 여행일 실시간 예보는 이번 범위 밖이다. 미검증 전기·입국 세부 요건도 새로 생성하지 않는다.
- 이전 `US_AU_SUPPORT.md`, `TRAVEL_DATA_COMPLETENESS_AUDIT.md`의 호주 기후 미지원 설명은 당시 기록이며 현재 지원 범위는 이 문서를 따른다.
