자료 정리 기준일·실제 원본 확인일: **2026-10-25**. 대상은 기존 VN 국가의 hanoi / danang / nhatrang / phuquoc이며 하이퐁은 추가하지 않았다.

- [기상청 하노이](https://www.weather.go.kr/w/weather/worldwide.do?cityCode=308&continentCode=C01&countryCode=170): 표의 최저·최고·강수량 및 자료기간(1991 ~ 2020)을 실제 다운로드해 확인.
- [WMO 하노이](https://worldweather.wmo.int/en/city.html?cityId=308), [공개 원본 JSON](https://worldweather.wmo.int/en/json/308_en.json): 도시명·기간과 12개월 기온·강수량을 기상청 표와 대조.
- [JMA 다낭 48855](https://www.data.jma.go.jp/tcc/tcc/products/climate/normal/parts/NrmMonth_e.php?stn=48855): 월평균·강수량.
- [WMO 다낭](https://worldweather.wmo.int/en/city.html?cityId=656), [공개 원본 JSON](https://worldweather.wmo.int/en/json/656_en.json): 평균 일최고·일최저 및 1991–2020 기간.
- [JMA 나트랑 48877](https://ds.data.jma.go.jp/gmd/tcc/tcc/products/climate/climatview/graph_mkhtml_nrm.php?e=7&k=0&m=9&n=48877&r=1&s=1&y=2026): 월평균·강수량.
- [JMA 푸꾸옥 48917](https://www.data.jma.go.jp/tcc/tcc/products/climate/normal/parts/NrmMonth_e.php?stn=48917): 월평균·강수량.
- [JMA ClimatView 자료 설명](https://www.data.jma.go.jp/tcc/tcc/products/climate/climatview/outline.html): 월평균 기온·월강수량 평년값의 기준기간이 1991–2020임을 확인. URL에 들어 있는 2026년은 이 평년값의 관측기간이 아니다.

공식 원본은 `src/service/data/raw/vn/`에 저장했다. `collection-manifest.json`에는 URL·확인일·SHA-256을 기록한다. WMO JSON은 개발 중 공개 원본 확인에만 사용하며 앱 실행 중 호출하지 않는다. WMO의 옛 회원자료 전달일 필드는 새 검증일로 바꾸지 않았다.

### 계산값과 관측소 한계

- 하노이: `(평균 일최고 + 평균 일최저) / 2`를 정수 0.1°C 단위로 계산한 뒤 소수 첫째 자리 반올림. 예: 1월 (20.0 + 14.6) / 2 = **17.3°C**. 카드·모달·기후 설명에 ‘계산 참고’를 표시하며 공식 직접 월평균 관측값이라고 부르지 않는다. JMA 48820을 조사했으나 월평년값 표가 없는 응답이었다. WWIS 308에 WMO 관측소 번호가 명시되지 않아 다른 관측소 직접 평균으로 교체하지 않았다.
- 다낭: JMA 좌표 16.07N / 108.35E, WMO 도시 좌표 16.08N / 108.22E로 다르다. 동일 관측지의 동질성까지 확인한 것으로 표시하지 않는다. 사용자 지정대로 JMA 평균·강수량과 WMO 최고·최저를 **항목별 별도 출처**로 등록하고 화면과 방법 설명에 차이를 명시했다. 숫자를 일치시키려고 재계산하지 않는다. WMO 강수량은 JMA와 다르므로 채택하지 않았다.
- 나트랑: WMO WWIS 3027의 1991–2020 최고·최저 자료도 조사했다. 하지만 WMO 도시 좌표 12.26N / 109.20E와 JMA 48877 좌표 12.22N / 109.22E가 다르고 동일 관측소 번호 연결을 입증하지 못해 최고·최저를 채택하지 않았다. 조사 원본은 research 파일로 보관하며 앱 데이터에는 넣지 않았다.
- 푸꾸옥: 조사한 WMO 도시 목록 및 JMA 표에서 동일 관측소·기간의 최고·최저 월평년값을 확보하지 못했다. null 유지.
- 항목별 결측 연수·관측소 이전 전체 이력은 해당 표만으로 재검증하지 못했다. JMA가 통신 누락·관측소 이전 등 자료 공백 가능성을 안내한다는 점을 전제로 게시 평년값을 사용한다.

## 화면·추천 연결

국가별 화면은 복제하지 않고 기존 `getClimateMonth` → `getStationClimateMonth` → `getTripClimate` → TripBrief / WeatherGuide / getClothingPreview / getDefaultBagItems 경로를 재사용한다. 공통 정적 관측소 어댑터에 항목별 출처·계산 기준·부분 결측을 지원하도록 확장했다. 대만 정적 원본과 다른 국가의 기후 데이터 파일은 수정하지 않았다.

평균 최고·최저가 없더라도 확인된 평균기온과 강수량을 표시한다. 추천은 필요한 입력이 있는 규칙만 평가한다. 기존 비 대비 기준인 월강수량 100mm 이상은 우산 및 우비의 선택 후보로 유지한다. 최고·최저가 모두 없는 경우에만 월평균 25°C 이상을 참고하는 보수적인 반팔 검토 규칙을 추가했으며, 이유에 평균만 사용한 서비스 제안임을 표시한다. 기존 자료가 충분한 국가에는 이 대체 규칙이 적용되지 않는다.

하노이 1월에는 얇은 긴팔·얇은 외투, 다낭 11월에는 반팔·우산 및 우비, 나트랑 11월·푸꾸옥 9월에도 확인된 평균과 강수량 기반 후보가 표시된다. 관광/야외 목적의 운동화, 출장 셔츠 등 기존 목적 필터를 유지한다. 동일 체크리스트 ID를 사용해 중복 없이 반영한다. 기존 후보에 없는 수영복·샌들·자외선 용품 ID를 새로 만들거나 모든 여행에 강제하지 않았다.

월강수량은 장기 월누적 평균이며 일강수량·우천 확률·여행 중 예상량이 아니다. 실제 예보와 개인 활동에 따라 최종 준비하도록 기존 안내문을 유지한다.

## 수정·추가 파일

- `src/service/data/vnClimate.generated.ts`, `raw/vn/`: 48개월 정적 수치·항목별 출처 및 원본.
- `scripts/build_vn_climate.mjs`: 원본 오프라인 파싱, KMA/WMO 교차 대조 및 결측·기간 검사.
- `src/service/data/stationClimate.ts`, `cities.ts`, `sources.ts`: 공통 조회·지원 상태·출처 등록.
- `src/service/data/clothing.ts`, `src/service/travel-info/guideModel.ts`: 부분 자료별 추천과 계산 참고 포맷 지원.
- `src/service/my-bag/TripBrief.tsx`, `src/service/travel-info/WeatherGuide.tsx`: 하노이 계산 라벨·항목별 출처, 미확인 부가 항목 숨김.
- `tests/vn-climate.test.mjs`, `scripts/verify_vn_ui.mjs`: 48개월·원본 해시·추천·체크리스트·실제 화면 검증.
- 기존 테스트 6개 파일: 베트남을 미수집 국가로 보던 검사 대상을 여전히 미수집인 태국으로 변경. 다른 국가 데이터와 회귀 검사는 유지.

전기 규격·플러그 SVG·항공안전 팝업·PACK LESS·LAST MINUTE BAG 등의 구현은 변경하지 않았다.
